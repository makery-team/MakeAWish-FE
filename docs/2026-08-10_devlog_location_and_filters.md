# [MakeAWish-FE] 매장 위치 및 전국 지역 필터 개선 (2026-08-10)

## 1. 개요
사장님 앱에서 주소를 등록/수정했을 때 위도 및 경도 좌표가 매핑되지 않아 지도상에 매장 핀이 표시되지 않는 현상을 수정하기 위해, 프론트엔드의 관련 UI 및 상태를 연동했습니다. 추가로, 기존 서울에 국한되어 있던 지역 필터를 전국 주요 지역으로 확장했습니다.

## 2. 변경 내용

### 2.1 매장 주소 매핑 개선
- `types/index.ts`의 `ConversationState`에 `shopAddress` 추가
- `order-reminder-card.tsx`에서 AI 추천 및 매장 선택 시 하드코딩된 가짜 주소가 나타나는 현상 제거
- `mapService.getStoreDetail(storeId)`를 활용하여, 주문 상담 시 실제 백엔드에 저장된 도로명 주소가 출력되도록 `useEffect` 기반 동적 로딩 구현

### 2.2 지역 필터 전국망 확대
- 기존 `constants/seoul-districts.ts` (서울 한정 데이터)를 `constants/korea-districts.ts`로 교체
- 경기, 인천, 부산, 대구, 광주, 대전, 제주 등 전국 주요 시도 및 시군구 데이터를 하드코딩하여 UI 지역 선택지 대폭 확대
- `map-view.tsx`에서 사용하는 타입(`SeoulGu` -> `RegionGu`) 및 필터링 로직 업데이트

## 3. 유의 사항
- 핀 매핑은 백엔드의 카카오 지오코딩 결과(위/경도)에 의존합니다.
- 백엔드에 `KAKAO_REST_API_KEY` 환경변수가 세팅되어 있어야만 사장님이 매장 등록 시 정상 좌표가 발급되며, 그 좌표 기반으로 프론트엔드 지도에 표시됩니다.
