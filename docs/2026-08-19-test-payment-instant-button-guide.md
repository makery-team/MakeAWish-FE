# 2026-08-19 토스페이먼츠 모달 테스트 원클릭 승인 버튼 추가 가이드

## 1. 개요
- **배경**: 모바일 에뮬레이터나 실기기 테스트 환경에서 토스페이/KB Pay 등 실제 결제 앱이 미설치된 경우, 구글 플레이스토어로 연결되거나 복잡한 본인인증 절차를 거쳐야 하는 불편함이 발생
- **목적**: 개발 및 테스트 환경에서 결제 모달 상단에 원클릭 테스트 승인 버튼을 제공하여, 별도의 앱 설치 및 본인인증 없이 1초 만에 `결제 완료 (PAID)` 상태로 전환하고 후속 플로우(제작/픽업/리뷰)를 빠르게 점검할 수 있도록 지원

---

## 2. 주요 구현 사항
- **`components/TossPaymentModal.tsx`**:
  - 결제 요약 바 하단에 `⚡ 테스트 환경: 원클릭 결제 승인하기 (인증 생략)` 버튼 배치
  - 클릭 시 `test_bypass_{timestamp}` 키를 발급하여 백엔드 `PaymentService.confirmTossPayment`에 전달 ➔ 즉시 주문 상태 `PAID` 전환
