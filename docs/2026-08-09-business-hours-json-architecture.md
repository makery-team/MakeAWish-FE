# 매장 운영시간(businessHours) JSON 아키텍처 개편 스펙

## 1. 개요
기존에는 매장의 운영시간(`hours` 필드)을 `"매일 09:00 - 20:00 (월요일 휴무)"`와 같은 단순 포맷팅된 문자열로 다루었습니다. 
하지만 소비자 앱에서의 실시간 영업 여부 판별(영업 중/종료) 및 풍부한 UI 제공, 그리고 사장님 앱에서의 다차원 편집 폼 유지를 위해 데이터를 구조화된 JSON 배열 형태로 파싱하도록 풀스택 아키텍처를 개편했습니다.

## 2. 변경된 데이터 스펙 (JSON Array)
운영시간 데이터는 이제 아래와 같은 7일 단위의 객체 배열 형태(JSON String)로 백엔드에서 응답됩니다.
```json
[
  {"day":"월","open":"09:00","close":"20:00","closed":false},
  {"day":"화","open":"09:00","close":"20:00","closed":false},
  {"day":"수","open":"09:00","close":"20:00","closed":false},
  {"day":"목","open":"09:00","close":"20:00","closed":false},
  {"day":"금","open":"09:00","close":"20:00","closed":false},
  {"day":"토","open":"10:00","close":"18:00","closed":false},
  {"day":"일","open":"10:00","close":"18:00","closed":true}
]
```

## 3. 소비자 앱 (MakeAWish-FE) 핵심 변경 사항
- **위치:** `components/shop-detail.tsx`
- 기존 문자열 렌더링 방식에서 벗어나, API 응답으로 받은 JSON 배열 문자열을 `JSON.parse()`로 파싱합니다.
- 파싱된 객체의 `closed` 여부 및 요일 정보를 분석하여, 휴무일은 붉은색 텍스트로, 요일별로 정돈된 리스트 UI(테이블) 형태로 소비자에게 명확하게 렌더링하도록 뷰를 리팩토링했습니다.

## 4. 사장님 앱 및 백엔드 연관 변경 사항
- **백엔드 (MakeAWish-BE):** 255자 길이 제한 문제(500 에러)를 방지하기 위해 `hours` 컬럼을 `TEXT`로 마이그레이션했습니다.
- **사장님 앱 (MakeAWish-FE-Owner):** 텍스트를 전송하지 않고 7일 단위 배열을 통째로 JSON 직렬화하여 송신 및 역직렬화하여 바인딩합니다.
